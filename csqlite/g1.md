# Chapter 1: Introduction to CSQLite

## What is CSQLite?

CSQLite is a Swift Package Manager wrapper that packages the SQLite C library as a Swift module. Unlike many SQLite wrappers that provide a Swift-native API, CSQLite gives you direct access to the complete SQLite C API within Swift. This means:

- **No abstraction overhead** - you work directly with SQLite's battle-tested C API
- **Complete feature access** - every SQLite feature is available
- **Predictable performance** - you control exactly what happens
- **Simple integration** - just add the package and import it

## Why Choose CSQLite Over Other Wrappers?

| Feature | CSQLite | GRDB | SQLite.swift |
|---------|---------|------|--------------|
| Swift-native API | ❌ (C API) | ✅ | ✅ |
| Full SQLite features | ✅ | ✅ | ⚠️ (Limited) |
| Zero overhead | ✅ | ⚠️ | ⚠️ |
| Custom compile options | ✅ (via traits) | ❌ | ❌ |
| Memory control | ✅ (explicit) | ⚠️ (hidden) | ⚠️ (hidden) |

**Choose CSQLite when you need:**

**Choose other wrappers when you need:**

## SQLite Version and Included Extensions

CSQLite includes SQLite with these features **enabled by default**:

### Built-in Extensions (Always Included)
```sql
-- decimal extension for exact decimal arithmetic
SELECT decimal_add('1.23', '4.56');  -- Returns '5.79'

-- ieee754 extension for floating-point representation
SELECT ieee754(3.14159);  -- Returns binary representation

-- series extension for generating sequences
SELECT value FROM generate_series(1, 5);  -- Returns 1,2,3,4,5

-- sha3 extension for cryptographic hashing
SELECT sha3_256('Hello');  -- Returns SHA-3 256-bit hash

-- uuid extension for UUID generation
SELECT uuid4();  -- Returns RFC 4122 UUID
```

### Default-Enabled Features (Can Be Disabled)

```sql
-- FTS5 Full-Text Search
CREATE VIRTUAL TABLE documents USING fts5(title, content);
INSERT INTO documents VALUES ('Swift Programming', 'Learn about Swift');
SELECT * FROM documents WHERE content MATCH 'Swift';

-- Math functions
SELECT sin(3.14159), log(100), pow(2, 8);

-- R*Tree spatial indexing
CREATE VIRTUAL TABLE locations USING rtree(id, minX, maxX, minY, maxY);

-- Percentile functions
SELECT median(value) FROM data;  -- 50th percentile

-- Database snapshots
-- Use sqlite3_snapshot_get() and sqlite3_snapshot_open()

-- sqlite_stmt virtual table
SELECT * FROM sqlite_stmt;  -- Shows prepared statements

-- sqlite_stat4 table
ANALYZE;  -- Populates stat4 for better query planning
```

### Additional Features (Disabled by Default)

```sql
-- Session extension for change tracking
CREATE TABLE changes USING session;  -- Track database changes

-- GeoPoly extension for GIS operations
SELECT geopoly_area(polygon_data) FROM geometries;
```

## Building CSQLite - Understanding Package Traits

When you add CSQLite to your project, you can customize its build using **package traits** (Swift 6.1+). Here's a complete breakdown:

### Threading Mode (Choose One)

```swift
// Example Package.swift showing different threading options

// Option 1: Single-threaded (Default, recommended)
.package(
    url: "https://github.com/sbooth/CSQLite.git",
    from: "1.0.0",
    traits: ["THREADSAFE_0"]  // Default, safest
)

// Option 2: Multi-threaded
.package(
    url: "https://github.com/sbooth/CSQLite.git",
    from: "1.0.0",
    traits: ["THREADSAFE_2"]
)

// Option 3: Serialized (thread-safe but slower)
.package(
    url: "https://github.com/sbooth/CSQLite.git",
    from: "1.0.0",
    traits: ["THREADSAFE_1"]
)
```

### Double-Quote String Handling (Choose One)

```swift
// Strict mode (Default, recommended)
.package(..., traits: ["DQS_0"])  // Disallows "quoted" identifiers

// Permissive mode (SQLite default, not recommended)
.package(..., traits: ["DQS_3"])  // Allows "quoted" strings as literals
```

### Enabling Optional Features

```swift
// Enabling additional features
.package(
    url: "https://github.com/sbooth/CSQLite.git",
    from: "1.0.0",
    traits: [
        "ENABLE_SESSION",      // Session extension for change tracking
        "ENABLE_FTS4",         // Older FTS version
        "ENABLE_GEOPOLY",      // Geographic polygon support
        "ENABLE_PREUPDATE_HOOK" // Pre-update triggers
    ]
)
```

### Complete Custom Build Example

```swift
// Package.swift
// swift-tools-version: 6.1

import PackageDescription

let package = Package(
    name: "MyApp",
    dependencies: [
        .package(
            url: "https://github.com/sbooth/CSQLite.git",
            from: "1.0.0",
            traits: [
                // Threading: Multi-threaded
                "THREADSAFE_2",
                // Double-quote strings: Strict mode
                "DQS_0",
                // Features: Session + GeoPoly
                "ENABLE_SESSION",
                "ENABLE_GEOPOLY"
            ]
        )
    ],
    targets: [
        .target(
            name: "MyApp",
            dependencies: ["CSQLite"]
        )
    ]
)
```

## Understanding C Interop in Swift

When using CSQLite, you'll work extensively with C types:

```swift
import CSQLite

// C types you'll encounter
typealias DatabasePointer = OpaquePointer      // sqlite3*
typealias StatementPointer = OpaquePointer    // sqlite3_stmt*
typealias CString = UnsafePointer<CChar>     // const char*
typealias MutableCString = UnsafeMutablePointer<CChar> // char*
typealias VoidPointer = UnsafeMutableRawPointer?      // void*
```

### Basic C Interop Patterns

```swift
// 1. Opening a database - returning a pointer
var db: OpaquePointer?
let result = sqlite3_open("database.db", &db)  // &db passes the address

// 2. Working with C strings
let sql = "CREATE TABLE users(id INTEGER, name TEXT)"
sql.utf8CString.withUnsafeBufferPointer { buffer in
    guard let baseAddress = buffer.baseAddress else { return }
    // baseAddress is UnsafePointer<CChar> - compatible with const char*
    sqlite3_exec(db, baseAddress, nil, nil, nil)
}

// 3. Binding parameters
let stmt: OpaquePointer? = ...
let name = "Alice"
name.withCString { cString in
    sqlite3_bind_text(stmt, 1, cString, -1, SQLITE_TRANSIENT)
}

// 4. Reading column data
let textPointer = sqlite3_column_text(stmt, 0)  // UnsafePointer<UInt8>?
if let pointer = textPointer {
    let string = String(cString: pointer)  // Convert to Swift String
}
```

## Quick Start: Complete Working Example

Here's a complete example that creates a database, inserts data, and queries it:

```swift
import CSQLite

class CSQLiteDemo {
    private var db: OpaquePointer?
    
    func run() throws {
        // 1. Open database
        try openDatabase("demo.db")
        defer { closeDatabase() }
        
        // 2. Create table
        try createTable()
        
        // 3. Insert data
        try insertUser(id: 1, name: "Alice", email: "alice@example.com")
        try insertUser(id: 2, name: "Bob", email: "bob@example.com")
        
        // 4. Query data
        let users = try fetchUsers()
        for user in users {
            print("User: \(user.name) (\(user.email))")
        }
        
        // 5. Transaction example
        try performTransaction()
    }
    
    private func openDatabase(_ path: String) throws {
        let result = sqlite3_open(path, &db)
        guard result == SQLITE_OK else {
            let error = String(cString: sqlite3_errmsg(db))
            throw DatabaseError.openFailed(error)
        }
        print("✅ Database opened: \(path)")
    }
    
    private func closeDatabase() {
        if let db = db {
            let result = sqlite3_close(db)
            if result == SQLITE_OK {
                print("✅ Database closed")
            } else {
                print("⚠️ Error closing database")
            }
            self.db = nil
        }
    }
    
    private func createTable() throws {
        let sql = """
            CREATE TABLE IF NOT EXISTS users (
                id INTEGER PRIMARY KEY,
                name TEXT NOT NULL,
                email TEXT UNIQUE NOT NULL,
                created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
            )
        """
        try execute(sql)
        print("✅ Table created/verified")
    }
    
    private func insertUser(id: Int, name: String, email: String) throws {
        let sql = "INSERT OR REPLACE INTO users (id, name, email) VALUES (?, ?, ?)"
        
        var stmt: OpaquePointer?
        defer { sqlite3_finalize(stmt) }
        
        // Prepare statement
        guard sqlite3_prepare_v2(db, sql, -1, &stmt, nil) == SQLITE_OK else {
            throw DatabaseError.prepareFailed(String(cString: sqlite3_errmsg(db)))
        }
        
        // Bind parameters
        sqlite3_bind_int(stmt, 1, Int32(id))
        sqlite3_bind_text(stmt, 2, name, -1, SQLITE_TRANSIENT)
        sqlite3_bind_text(stmt, 3, email, -1, SQLITE_TRANSIENT)
        
        // Execute
        guard sqlite3_step(stmt) == SQLITE_DONE else {
            throw DatabaseError.executeFailed(String(cString: sqlite3_errmsg(db)))
        }
        
        print("✅ Inserted user: \(name)")
    }
    
    private func fetchUsers() throws -> [User] {
        let sql = "SELECT id, name, email FROM users ORDER BY id"
        var stmt: OpaquePointer?
        defer { sqlite3_finalize(stmt) }
        
        guard sqlite3_prepare_v2(db, sql, -1, &stmt, nil) == SQLITE_OK else {
            throw DatabaseError.prepareFailed(String(cString: sqlite3_errmsg(db)))
        }
        
        var users: [User] = []
        while sqlite3_step(stmt) == SQLITE_ROW {
            let id = Int(sqlite3_column_int(stmt, 0))
            let name = String(cString: sqlite3_column_text(stmt, 1))
            let email = String(cString: sqlite3_column_text(stmt, 2))
            users.append(User(id: id, name: name, email: email))
        }
        
        print("✅ Fetched \(users.count) users")
        return users
    }
    
    private func performTransaction() throws {
        try execute("BEGIN TRANSACTION")
        
        do {
            try insertUser(id: 3, name: "Charlie", email: "charlie@example.com")
            try insertUser(id: 4, name: "Diana", email: "diana@example.com")
            try execute("COMMIT")
            print("✅ Transaction committed")
        } catch {
            try? execute("ROLLBACK")
            print("⚠️ Transaction rolled back: \(error)")
            throw error
        }
    }
    
    private func execute(_ sql: String) throws {
        try sql.utf8CString.withUnsafeBufferPointer { buffer in
            guard let pointer = buffer.baseAddress else {
                throw DatabaseError.invalidSQL
            }
            var errMsg: UnsafeMutablePointer<CChar>?
            
            let result = sqlite3_exec(db, pointer, nil, nil, &errMsg)
            defer { sqlite3_free(errMsg) }
            
            guard result == SQLITE_OK else {
                let error = errMsg.map { String(cString: $0) } ?? "Unknown error"
                throw DatabaseError.executeFailed(error)
            }
        }
    }
    
    struct User {
        let id: Int
        let name: String
        let email: String
    }
    
    enum DatabaseError: Error {
        case openFailed(String)
        case prepareFailed(String)
        case executeFailed(String)
        case invalidSQL
    }
}

// Run the demo
let demo = CSQLiteDemo()
try? demo.run()
```

## Quick Reference: Common SQLite C API to Swift Mappings

| SQLite C API | Swift Equivalent | Notes |
|-------------|------------------|-------|
| `sqlite3 *` | `OpaquePointer?` | Database handle |
| `sqlite3_stmt *` | `OpaquePointer?` | Prepared statement |
| `const char *` | `UnsafePointer<CChar>` | C string input |
| `char *` | `UnsafeMutablePointer<CChar>` | C string output |
| `void *` | `UnsafeMutableRawPointer?` | Generic pointer |
| `int` | `Int32` | SQLite uses 32-bit ints |
| `sqlite3_int64` | `Int64` | 64-bit integer |
| `sqlite3_destructor_type` | `@convention(c) (UnsafeMutableRawPointer?) -> Void` | Destructor callback |
| `sqlite3_callback` | `@convention(c) (UnsafeMutableRawPointer?, Int32, UnsafeMutablePointer<UnsafeMutablePointer<CChar>?>?, UnsafeMutablePointer<UnsafeMutablePointer<CChar>?>?) -> Int32` | Result callback |
